# Resume / Portfolio

Shankar Tiwari's portfolio, served free on GitHub Pages: https://tiwari91.github.io/resume/

- `index.html` – portfolio: intro, app cards (screenshot, Live, Code), infrastructure repos, brief experience, skills, publications.
- `cv.html` – the full long-form resume (print / save as PDF from the page).
- `assets/shots/` – app screenshots (1280x800 captures, WebP).
- `style.css`, `theme.js` (light/dark, follows the system, remembers a manual choice), `index.js` (filter chips).

Static HTML/CSS/JS, no framework, no build step. Preview locally with `python3 -m http.server`.
