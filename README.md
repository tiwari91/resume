# Resume / Portfolio

Shankar Tiwari's homepage, served on GitHub Pages: https://tiwari91.github.io/resume/

- `index.html`: short intro, projects (one lead project, two featured, the rest as rows grouped by theme), work history.
- `cv.html`: the full resume (print or save as PDF from the page).
- `assets/shots/`: app screenshots (1280x800 captures, WebP).
- `style.css` is shared by all pages. `theme.js` is the light/dark toggle (follows the system, remembers a manual choice).

Plain HTML and CSS, set in Source Serif 4 from Google Fonts. No framework, no build step. Preview locally with `python3 -m http.server`.
